# OldRoot OPI — Patch 1.0 (2026-11-11)

## Status
Approved universal rating terminology; rebalanced baseline values prepared for website review.

## Scale
All eleven capability categories and optional conditional readings use the **same** 0–100 neutral performance bands:

| Range | Label | Interpretation |
| --- | --- | --- |
| 0.0–2.9 | Minimal | Little measurable capability |
| 3.0–4.9 | Limited | Restricted capability |
| 5.0–9.9 | Standard | Within the index reference range |
| 10.0–19.9 | Elevated | Noticeably above reference |
| 20.0–34.9 | Advanced | Substantially developed capability |
| 35.0–49.9 | Exceptional | Unusually high performance |
| 50.0–69.9 | Extreme | Extraordinary performance |
| 70.0–89.9 | Apex | Among the highest recorded levels |
| 90.0–100.0 | Zenith | Uppermost index range |

The labels describe capability only. They do **not** classify a character as human, enhanced, cosmic, or otherwise. Zenith is the index's uppermost band, not unlimited power.

## Reporting
- The baseline uses eleven regular stats. Its total and mean are arithmetic-derived analytics, not additional character scores, canonical fight predictions, or privileged **Official OPI** designations.
- Conditional ratings are displayed and banded separately and are **excluded** from the baseline arithmetic. Gila Monster's Nocturnal Senses 34.5 and Desert Mobility 30.1 are conditional; Agent Emerald's Precision Pill Senses remains 16.1.
- Amari Razman remains in the Character Registry and her dossier, but is intentionally excluded from OPI Analytics, and her individual OPI and former aggregate are not published.
- Liontone remains publicly released, with all existing numerical ratings untouched until the creator approves a replacement decision.
