# OldRoot local map data

`world-110m.json` is a local copy of the 110m world topology used by the OldRoot World Index so the globe does not require a runtime geometry download to render country/land detail.

Source lineage: Natural Earth → world-atlas / Vega distribution. The data is used as static geographic reference material. The World Index retains a remote world-atlas URL only as a fallback if the local file cannot be loaded.
