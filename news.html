FEATURED / SITE UPDATE
September 2026 · OldRoot Studios

The site is becoming the universe’s front door.

OldRoot’s first public site began as a functional registry. The current rebuild pushes it toward something more deliberate: cleaner typography, stronger hierarchy, deeper world navigation, an actual lore index, an events registry, a guided Start Here page, and a modern dispatch desk.

The next visual phase will replace temporary and overly photoreal character imagery with a more intentional comic-editorial art direction.

OR-WEB-0003 · September 26, 2026 · Locations

Nearby globe locations now cluster cleanly.

Dense map areas now collapse into a counted cluster marker instead of stacking pins on top of each other. Selecting a cluster opens a nearby-location navigator that supports scrolling, arrow keys, Previous/Next controls, and direct selection. The greater D.C. cluster includes Baltimore, St. Dorsey, and Washington, D.C. as a geographic reference.

Open clustered Locations →
OR-WEB-0001 · September 26, 2026 · Locations

Locations globe rebuilt for stability.

The globe has returned to a focused global-navigation role. Unstable extreme zoom and live city-boundary behavior were removed; selection, drag rotation, controlled zoom, dossier links, keyboard access, and mobile interaction were rebuilt around a simpler state model. St. Dorsey is now explicitly marked as a schematic D.C.-area placement rather than an exact public coordinate.
